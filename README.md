# Snake Game

This is a simple Snake game implemented in Python using the Pygame library.

## How to Play

- Use the arrow keys or WASD keys to control the snake's direction.
- The snake will grow in length when it eats the food.
- The game will end if the snake collides with the boundaries of the window or itself.
- Your score is displayed at the end of the game.
